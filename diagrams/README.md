# Diagramas

- `arquitectura.mmd` es la fuente Mermaid editable del diagrama lógico.
- `arquitectura_referencia.png` es un diagrama PNG de referencia incluido con la guía complementaria.

Al generar el diagrama final para la entrega, actualiza la captura/diagrama con los IDs, IPs, CIDR y nombres reales del despliegue. No publiques datos de cuenta o recursos que tu institución considere sensibles.
